\section*{Summary}
The advent of high-performance computing has radically changed the aerospace industry's approach to wing design. In the past, wing sections were based closely on one of the wide range of standard geometries for which experimental data were already available, and optimisation was via extensive wind tunnel testing. Now, most initial section design is based on numerical calculations, with experimental work appearing later in the process. The advantage of this combined approach is that the experimental data which is the backbone of any development project is still obtained, but expensive wind tunnel tests can be targeted on the most promising designs identified by the (relatively) cheap computations. This computer-based project provides an introduction to the numerical design process, in the context of two-dimensional airfoil sections. Programming experience above and beyond Part I computing coursework activities is NOT necessary.

\section*{Week 1: The Panel Method}

\subsection*{Exercise 1: Point vortex stream function}

\textbf{Statement of exercise:} The stream function $\psi$ at $(x, y)$ due to a point vortex of circulation $\Gamma$, located at $(x_c, y_c)$, is given by
\begin{equation}
\psi(x, y) = -\frac{\Gamma}{2\pi} \log r,
\end{equation}
where
\begin{equation}
r^2 = (x - x_c)^2 + (y - y_c)^2
\end{equation}
Plot contours of $\psi$ in the region $-2.5 \leq x \leq 2.5$, $-2 \leq y \leq 2$, for $x_c = 0.75$, $y_c = 0.5$, $\Gamma = 3.0$.

\textbf{Step (i):} write a Matlab function \texttt{psipv.m} that returns the streamfunction value for a single $(x,y)$ location. The first line of the function file should be:
\begin{verbatim}
function psixy = psipv(xc,yc,Gamma,x,y)
\end{verbatim}
Note that the natural logarithm function in Matlab is \texttt{log( )}.

\textbf{Step (ii):} Write a script to generate matrices \texttt{xm}, \texttt{ym}, \texttt{psi} whose $(i,j)$th entries give the values of $x$, $y$, and $\psi$ at the $(i,j)$th grid point, i.e.
\begin{verbatim}
xm(i,j) = xmin + (i-1)*(xmax-xmin)/(nx-1);
ym(i,j) = ymin + (j-1)*(ymax-ymin)/(ny-1);
psi(i,j) = psipv(xc,yc,Gamma,xm(i,j),ym(i,j));
\end{verbatim}

The parameters \texttt{xmin}, \texttt{xmax}, \texttt{nx}, \texttt{ymin}, \texttt{ymax}, \texttt{ny}, \texttt{xc}, \texttt{yc}, \texttt{Gamma} are best set at the beginning of the script. Use \texttt{nx = 51} and \texttt{ny = 41}.

\textbf{N.B.} It's a good idea to include the commands \texttt{clear} and \texttt{close all} at the beginning of this and subsequent scripts. The first deletes all the variables lying around in the workspace from whatever you did last, and the second removes all previously generated figures.

\textbf{Step (iii):} Add a call to Matlab's contouring routine at the end of the script:
\begin{verbatim}
c = -0.4:0.2:1.2
contour(xm,ym,psi,c)
\end{verbatim}

\textbf{Assessment materials:} (a) listing of \texttt{psipv.m}, (b) listing of script, (c) contour plot.

\subsection*{Exercise 2: Reference vortex-sheet-panel stream function}

The stream function $\psi$ at $(X,Y)$ due to the linear vortex-sheet panel shown in Fig.~1 is given by
\begin{equation}
\psi(X,Y) = \gamma_a \left[ \left(1-\frac{X}{\Delta}\right)I_0 - \frac{I_1}{\Delta} \right] + \gamma_b \left[ \frac{X}{\Delta} I_0 + \frac{I_1}{\Delta}\right],
\end{equation}
where
\begin{align}
I_0 &= -\frac{1}{4\pi} \int_0^\Delta \log\left[(l-X)^2 + Y^2\right] \, dl \nonumber \\
&= -\frac{1}{4\pi} \left\{ X\log\left[X^2 + Y^2\right] - (X-\Delta)\log\left[(X-\Delta)^2 + Y^2\right] - 2\Delta \right. \nonumber \\
&\quad\quad\quad + \left. 2Y\left[\tan^{-1}\left(\frac{X}{Y}\right) - \tan^{-1}\left(\frac{X-\Delta}{Y}\right)\right] \right\}
\end{align}
and
\begin{align}
I_1 &= -\frac{1}{4\pi} \int_0^\Delta (l-X)\log\left[(l-X)^2 + Y^2\right] \, dl \nonumber \\
&= \frac{1}{8\pi} \left\{ \left[X^2 + Y^2\right]\log\left[X^2 + Y^2\right] - \left[(X-\Delta)^2 + Y^2\right]\log\left[(X-\Delta)^2 + Y^2\right] \right. \nonumber \\
&\quad\quad\quad - \left. 2X\Delta + \Delta^2 \right\}.
\end{align}

\textbf{Statement of exercise:} Equation (1) can be written as $\psi(X,Y) = \gamma_a f_a + \gamma_b f_b$, where $f_a$ and $f_b$ are known as `influence coefficients'. Plot contours of these coefficients in the region $-2.5 \leq x \leq 2.5$, $-2 \leq y \leq 2$, for $\Delta = 1.5$. Check your result by generating the corresponding stream functions for the discretised, multiple-point-vortex approximation to the panel shown in Fig.~2.

\textbf{Step (i):} write a Matlab function \texttt{refpaninf.m} that returns the influence coefficients for a single $(X,Y)$ location. The first line of the function file should be:
\begin{verbatim}
function [infa infb] = refpaninf(del,X,Yin)
\end{verbatim}

Here \texttt{infa} and \texttt{infb} are $f_a$ and $f_b$, and \texttt{del} is the value of $\Delta$. The input $y$ variable is \texttt{Yin} rather than \texttt{Y} because of numerical difficulties in (2) and (3) at the panel boundaries; these can be avoided by setting the following trap:
\begin{verbatim}
if abs(Yin) < 1e-19
    Y = 1e-19;
else
    Y = Yin;
end
\end{verbatim}

The inverse tangent function in Matlab is \texttt{atan( )}. You may also find yourself needing to write expressions that span multiple lines in your file. Put the continuation marker \texttt{...} at the end of the line to tell Matlab that the expression continues on the following one.

\textbf{Step (ii):} write a script to generate matrices of $x$, $y$ and influence coefficient values on a uniform grid, as in Example 1. Use the same number of grid points and set \texttt{del = 1.5}.

\textbf{Step (iii):} produce contour plots of \texttt{infa} and \texttt{infb}, with contour levels defined by the vector \texttt{c = -0.15:0.05:0.15}. (To avoid replacing the first plot with the second, bring up another figure window with the command \texttt{figure(2)} before contouring \texttt{infb}.)

\textbf{Step (iv):} edit your script to include the discretised panel estimates of the stream function at each grid point. This will entail looping over all the point vortices shown in Fig.~2, and adding the individual contributions calculated by \texttt{psipv} together to give the overall panel contribution. Use $n_v = 100$ vortices.

\textbf{Step (v):} generate contour plots of the approximated influence coefficients, for comparison with your \texttt{refpaninf} results.

\textbf{Assessment materials:} (a) listing of \texttt{refpaninf.m}, (b) listing of script, (c) four contour plots, showing exact and approximate values of $f_a$, $f_b$.

\subsection*{Exercise 3: General vortex-sheet-panel stream function}

\textbf{Statement of exercise:} The linear vortex-sheet panel shown in Fig.~3 has a general location specified by its edge coordinates, $(x_a,y_a)$ and $(x_b,y_b)$. For the case $(x_a,y_a) = (4.1,1.3)$, $(x_b,y_b) = (2.2,2.9)$, plot contours of the influence coefficients in the region $0 \leq x \leq 5$, $0 \leq y \leq 4$. \textbf{Step (i):} write the Matlab routine defined by
\begin{verbatim}
function [infa infb] = panelinf(xa,ya,xb,yb,x,y)
\end{verbatim}

This routine is to return the influence coefficients $f_a$, $f_b$ at $(x,y)$ due to our general panel. The first stage is to work out the coordinates of $(x,y)$ in the standard panel reference frame. \subsection*{Exercise 5: Panel method solution for the cylinder flow}

\textbf{Statement of exercise:} Implement a panel method and solve for the flow past a unit radius cylinder at incidences $\alpha = 0$, $\alpha = 0.1$, subject to the condition that the surface vortex sheet has zero strength at the point $(1,0)$.

\subsubsection*{Panel method formulation}

First, observe the nomenclature specified in Fig.~4. The panels are numbered anti-clockwise from the `trailing edge', $(1,0)$. The $ip$'th panel is defined by the $ip$'th and $(ip+1)$'th coordinate pair, $(x_{ip}, y_{ip})$ and $(x_{ip+1}, y_{ip+1})$.

The contribution to the stream function from this panel is $\gamma_{ip} f_a^{(ip)} + \gamma_{ip+1} f_b^{(ip)}$, where the influence coefficients now have a superscript to indicate their associated panel, while $\gamma_a$ and $\gamma_b$ have been replaced by $\gamma_{ip}$ and $\gamma_{ip+1}$. The contribution of all the panels to the stream function at one of the panel edges, $(x_i, y_i)$, is thus
\begin{equation}
\psi_p(x_i, y_i) = \sum_{ip=1}^{n_p} \left[ \gamma_{ip} f_a^{(ip)}(x_i, y_i) + \gamma_{ip+1} f_b^{(ip)}(x_i, y_i) \right].
\end{equation}

(Note that, as for the surface coordinates, the trailing-edge value for the vortex sheet strength, $\gamma_1$, is repeated as $\gamma_{n_p+1}$.) We can rearrange this expression as follows:
\begin{equation}
\psi_p(x_i, y_i) = \sum_{j=1}^{n_p+1} [\Psi_p]_{i,j} \gamma_j,
\end{equation}
where
\begin{align}
[\Psi_p]_{i,j} &= f_a^{(j)}(x_i, y_i), \quad j = 1; \nonumber \\
&= f_a^{(j)}(x_i, y_i) + f_b^{(j-1)}(x_i, y_i), \quad j = 2,3,\ldots,n_p; \nonumber \\
&= f_b^{(j-1)}(x_i, y_i), \quad j = n_p + 1.
\end{align}

This alternative formulation expresses $\psi_p(x_i, y_i)$ as the product of the $i$'th row of a matrix $\Psi_p$ with the column vector of vortex sheet strength values. Finally, the overall stream function $\psi$ is given by $\psi_p + \psi_{fs}$ where $\psi_{fs}$ is the free stream contribution.

We can now assemble the set of equations required to solve for the unknown $\gamma_j$s. The condition that the cylinder surface is a streamline requires the stream function to be constant from panel edge to panel edge, i.e.
\begin{equation}
\psi(x_{i+1}, y_{i+1}) - \psi(x_i, y_i) = 0,
\end{equation}
for $i$ between 1 and $n_p - 1$. (Why can't we use the last panel as well?) Splitting the stream function into its (unknown) panel component and its (known) free-stream component, and using (4), we have
\begin{equation}
\sum_{j=1}^{n_p+1} \left\{ [\Psi_p]_{i+1,j} - [\Psi_p]_{i,j} \right\} \gamma_j = \psi_{fs}(x_i, y_i) - \psi_{fs}(x_{i+1}, y_{i+1}),
\end{equation}

This gives us $n_p - 1$ equations for the $n_p + 1$ unknown $\gamma_j$s. The final equations are supplied by the repetition $\gamma_{n_p+1} = \gamma_1$, and by the additional requirement on the vortex sheet strength at $(1,0)$, i.e.\ $\gamma_1 = 0$. (Once we start working with aerofoil geometries this will become our Kutta condition.) We thus complete our system of equations with two auxiliary relations:
\begin{align}
\gamma_1 &= 0, \\
\gamma_{n_p+1} &= 0.
\end{align}

Equations (6)--(8) can be written as
\begin{equation}
\mathbf{A}\boldsymbol{\gamma} = \mathbf{b},
\end{equation}
where $\mathbf{A}$ is an $(n_p+1) \times (n_p+1)$ matrix, $\boldsymbol{\gamma}$ is the vector of unknown $\gamma_{ip}$s, and $\mathbf{b}$ contains the stream function contributions. The solution is
\begin{equation}
\boldsymbol{\gamma} = \mathbf{A}^{-1}\mathbf{b}.
\end{equation}

\textbf{Step (i):} write the Matlab routine
\begin{verbatim}
function lhsmat = build_lhs(xs,ys)
\end{verbatim}
to assemble the matrix $\mathbf{A}$. The first stage in this routine is to identify the number of panels and initialize the intermediate matrix $\Psi_p$:
\begin{verbatim}
np = length(xs) - 1;
psip = zeros(np,np+1);
\end{verbatim}

Next, loop over the panel edge points, each of which corresponds to a row of $\Psi_p$, and fill the rows according to equations (5). Note that this will entail an inner loop, over panels, inside which you will need to call \texttt{panelinf} to obtain the influence coefficients needed to augment the appropriate entries in the matrix.

You can now build $\mathbf{A}$. Again, it should first be initialised:
\begin{verbatim}
lhsmat = zeros(np+1,np+1);
\end{verbatim}

If you can't see how to define its elements, go back to (9) and make sure you understand, in detail, how it follows from (6)--(8).

\textbf{Step (ii):} Write the Matlab routine
\begin{verbatim}
function rhsvec = build_rhs(xs,ys,alpha)
\end{verbatim}
to assemble the vector $\mathbf{b}$ in (9). You should first initialize $\mathbf{b}$ similarly to $\mathbf{A}$ in step (i), to ensure that you return a column, rather than row, vector. The entries then follow from (6), (7) and (8). Note that the stream function for the oncoming (unit) flow at incidence $\alpha$ is
\begin{equation}
\psi_{fs}(x, y) = y\cos\alpha - x\sin\alpha.
\end{equation}

\textbf{Step (iii):} write a script to perform the calculations. Your code from Exercise 4 will provide a useful starting point here. Once the flow incidence and cylinder geometry are defined, the commands
\begin{verbatim}
A = build_lhs(xs,ys);
b = build_rhs(xs,ys,alpha);
gam = A\b;
\end{verbatim}
will solve the equations.

\textbf{Step (iv):} add an output stage to your script. This should consist of a calculation of the total cylinder circulation and a plot of the surface velocity (ie \texttt{gam}) against $\theta/\pi$. Use the command \texttt{axis([0 2 -2.5 2.5])} to ensure that your plots are on the same scale.

\textbf{Assessment materials:} (a) listings of \texttt{build\_lhs.m} and \texttt{build\_rhs.m}, (b) listing of script, (c) plots of surface velocities for the two requested values of $\alpha$, (d) value of circulation for the non-zero value of $\alpha$.
